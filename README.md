# 💰 MoneyWise - 个人财务管理系统

一个简单易用的个人财务管理工具，帮助你追踪收入支出，实现财务自由。

## 🎯 功能特点
- ✅ 收入支出记录
- ✅ 消费分类统计
- ✅ 月度报表查看
- ✅ 储蓄率计算

## 🚀 快速开始

### 方法1：直接使用网页版
1. 访问 [项目链接]()
2. 开始记录你的财务数据

### 方法2：本地运行
1. 下载项目文件
2. 双击打开 `index.html`
3. 开始使用

## 📊 数据说明
所有数据都保存在你的浏览器本地，保护隐私安全。

## 🛠️ 技术栈
- HTML5
- CSS3
- JavaScript
- LocalStorage（数据存储）

## 📱 使用说明

### 添加交易记录
1. 点击"添加交易记录"按钮
2. 输入交易信息
3. 系统自动计算统计数据

### 查看报表
- 系统自动生成消费分类统计
- 实时更新储蓄率
- 月度收支对比
